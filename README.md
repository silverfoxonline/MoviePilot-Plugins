## 插件

### PT站开放注册监控

监测 PT 站注册页面是否开放，并仅在状态变为开放时发送通知。

自定义站点配置示例：

```json
[
  {
    "name": "SeedPool",
    "url": "https://seedpool.org/register"
  }
]
```
